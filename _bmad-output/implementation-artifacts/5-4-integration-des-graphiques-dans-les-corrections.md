# User Story: Intégration des Graphiques dans les Corrections

## Story Title
As a math teacher, I want the AI to seamlessly integrate generated graphics (TikZ diagrams, probability trees, variation tables) into LaTeX corrections, so that all visual elements compile correctly and enhance the pedagogical value of my corrections.

## Acceptance Criteria

### Functional Requirements
- [ ] When graphics are generated by the AI, they should be automatically inserted into the appropriate correction section
- [ ] Graphics should be properly positioned within the LaTeX document structure
- [ ] Each graphic should include:
  - Proper LaTeX environment (figure, center, etc.)
  - Appropriate caption and label for referencing
  - Correct scaling and positioning
- [ ] Support for multiple graphic types in a single correction
- [ ] Maintain proper document flow around inserted graphics

### Technical Requirements
- [ ] Implement AI prompt instructions for proper LaTeX graphic integration
- [ ] Handle graphic dependencies (TikZ packages, etc.)
- [ ] Integrate with existing correction generation workflow

## Technical Notes
- The extension should NOT handle the integration itself - this is the AI's responsibility
- The extension should NOT verify the correctness of the generated LaTeX - this is also the AI's responsibility
- Use structured prompts to guide AI in proper LaTeX graphic integration
- Include examples of well-integrated graphics in the prompts
